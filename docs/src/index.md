# QuicoptClient.jl

```
  JuMP.Model ──import_model──▶ Program ──encode──▶ wire bytes ──solve/HTTP──▶ result
```

```@docs
QuicoptClient
```

## Installation

```julia
using Pkg
Pkg.add("QuicoptClient")
```

All dependencies are public — `JuMP`, `ProtoBuf`, `HTTP`, `JSON3`. No solver and no
service internals ship with the client.

## Quickstart

```julia
using QuicoptClient, JuMP

m = Model()
@variable(m, 0 <= x <= 4)
@variable(m, 0 <= y <= 4)
@objective(m, Max, 3x + 2y)
@constraint(m, x + y <= 5)

result = solve(m)                      # POSTs to the service; prints the result banner
@show result.status result.objective result.solution
```

The first call mints a free API key, cached at `$XDG_CACHE_HOME/quicopt/free_key`
(`~/.cache/…` by default, `0o600`) and replayed on every later call — including from
later runs, so one caller keeps one key. Point `QUICOPT_KEY_PATH` at durable storage
where the home directory does not survive the run (CI, containers), or every run
mints a new key. Target a specific server with `solve(m; base_url = "…")`,
and use `async = true` for the first call against a freshly-booted server (its
worker warmup can time out a synchronous call).

## The wire schema

The wire `Program` is the published API contract
(`proto/quicopt/modeler/v1/program.proto`). The client's codec is **generated** from
that `.proto` via [ProtoBuf.jl](https://github.com/JuliaIO/ProtoBuf.jl) (under
`src/proto/`, regenerated by `gen/gen.jl`) — the client implements the contract
without forking it. Because proto3 omits zero-valued scalars and does not canonicalize
map order, the emitted bytes are *decode-equivalent* to the service's reference codec,
not byte-identical; a separate verification harness proves that equivalence.

## API reference

- [Modeling](@ref) — `import_model`, `encode`: JuMP model → wire `Program` → bytes.
- [Transport](@ref) — `solve`, `QuicoptError`: ship the bytes to the service.
